# Pocket Rogue

文字だけのカジュアルローグライク。
スマートフォンのブラウザで遊ぶ前提で、GitHub Pages に置いて URL で配る。
ホーム画面に追加すればアプリのように起動し、オフラインでも動く。

## 遊び方

- 画面下のボタンで 8 方向に移動。中央は待機
- ボタンを長押しすると連続移動。壁・敵の出現・被弾・階段で止まる
- 敵に向かって移動すると攻撃
- 斜めに動くとき、行き先が床でも両隣が壁なら通れない。この制限は敵にもかかる
  (壁抜けの敵だけが例外)
- ログは自分の行動が青、敵の行動が赤、情報が灰、警告が黄。
  最新のターンの行だけが明るく、それ以前は暗い。どこまでが今の 1 手の結果かが読める
- 敵のグリフは傷つくほど赤に寄る。半分以下で橙、1/4 以下で赤になる
- 被弾すると画面が一瞬赤く光る
- 敵を倒すと経験値が入る。**レベルが上がると最大 HP が 3 増え、HP が全快する。**
  瀕死のまま踏み込んで全回復を取りにいくかどうかが判断になる
- 必要経験値は `6 + レベル×(レベル+1)/2` で、レベルが上がるほど伸び幅も増える
- **攻撃力はレベルでは伸びない。武器で決まる。** 素の攻撃力 4 に武器の補正が乗る
- ダメージは 1 から最大値までの一様乱数ではなく、下限が最大値に比例する
  (自分は 6 割から、敵は 5 割から)
- 防御は被ダメージを減らすが、出目の 1/4 は必ず通る。防具を積んでも軽減率は 75% で止まる
- 敵にも防御力がある。硬さは系統で違う (重装が硬く、群れと俊敏は柔らかい)
- **自然回復は無い。** 回復手段はレベルアップの全回復、階を降りたときの +5、回復薬だけである。
  階層を降りただけでは強くならないので、倒す敵を選ぶことが判断になる
- アイテムは踏むと拾う。武器 `)` と防具 `[` は踏むと持ち替えるかどうかを聞かれる。
  持ち替えると今の装備は足元に落ちる。断った装備は、通っても二度は聞かれない
- 攻撃には命中率がある。武器ごとに違い、外すとダメージは 0 になる
- 防具には回避率がある。成立すると被弾しない
- 敵を倒すと、その系統に効く装備をたまに落とす
- 消耗品は方向ボタンの上のスロットをタップして使う (対象指定は無い)
  - 回復薬 `!`: HP を最大値の半分 (最低 8) 回復する
  - 雷の巻物 `?` (黄): 見えている敵全員にダメージ
  - 地図の巻物 `?` (水色): その階の地形をすべて表示する
- `>` に乗ると確認が出る。降りるかどうかを選ぶ (長押しの連続移動で踏んでも降りない)。
  やめたあとは、階段の上で待機するともう一度確認が出る
- 右上の ≡ から seed を確認・入力できる。同じ seed なら同じダンジョンになる
- PC はカーソルキー・テンキー・hjklyubn で移動、`.` か Space で待機

### 装備

定義は `src/equip.ts` にある。
軸を 2 つずつ持たせて、単純な上位互換が生まれないようにしてある。

| 種別 | 軸 1 | 軸 2 |
|---|---|---|
| 武器 | 攻撃力 | 命中率 |
| 防具 | 減算値 | 回避率 |

深さから決まる強さ (武器 `1 + 階/3 + 0〜1`、防具 `1 + 階/4`) に、種類ごとの補正が乗る。
系統特効はその系統の敵が落とす。ドロップ限定のものは床には出ない。

| 武器 | 系統 | 攻撃 | 命中 | 効果 |
|---|---|---|---|---|
| 短剣 | - | -1 | 95% | - |
| 剣 | - | +0 | 85% | - |
| 斧 | - | +2 | 70% | - |
| 群れ薙ぎ | 群れ | -1 | 85% | 隣接する敵すべてに当たる |
| 韋駄天突き | 俊敏 | +0 | 100% | 必ず当たる。回避を無視する |
| 鎧通し | 戦士 | -1 | 85% | 防御力を無視する |
| 祓いの杖 | 変則 | -1 | 90% | 分裂を止める |
| 大槌 | 重装 | +3 | 65% | (攻撃力の高さが再生を上回る) |
| 会心の刃 | ドロップ限定 | +0 | 85% | 25% で防御力を無視する |
| 双牙 | ドロップ限定 | -2 | 80% | 2 回攻撃する |

| 防具 | 系統 | 防御 | 回避 | 効果 |
|---|---|---|---|---|
| 革鎧 | - | -1 | 12% | - |
| 鎖帷子 | - | +0 | 5% | - |
| 板金鎧 | - | +2 | 0% | - |
| 群れよけの盾 | 群れ | +0 | 5% | 被弾時のスタミナ消費を抑える (スタミナ実装後) |
| 疾風の外套 | 俊敏 | -1 | 20% | (回避の高さが速い敵に効く) |
| 戦士殺しの鎧 | 戦士 | +2 | 0% | (減算値の高さが素直な強敵に効く) |
| 変則よけの護符 | 変則 | +0 | 5% | 腐食を防ぐ (腐食実装後) |
| 棘鎧 | 重装 | +1 | 0% | 近接攻撃に反撃する |
| 影衣 | ドロップ限定 | -2 | 28% | - |
| 金剛の鎧 | ドロップ限定 | +4 | 0% | - |

### 敵

特徴は「パッシブ (常に働く性質)」と「アクション (条件が揃ったとき確率で使う技)」に分かれる。
定義は `src/entity.ts` の `MONSTERS` にあり、1 行足せば新しい敵が出る。

系統は敵を役割で畳んだ分類で、装備の系統特効が効く相手を決める軸になる。
今は分類を持たせるだけで、まだ何の効果にも繋がっていない。

| 敵 | 系統 | 階 | 防御 | 回避 | パッシブ | アクション |
|---|---|---|---|---|---|---|
| ネズミ `r` | 群れ | B1〜B4 | 0 | 0% | なし (2〜3 匹の群れ) | なし |
| コウモリ `b` | 俊敏 | B1〜B6 | 0 | 10% | 俊敏 (1 ターン 2 回行動)、ふらつき | なし |
| ゴブリン `g` | 戦士 | B2〜B8 | 1 | 0% | なし | 連撃 30%: 2 回攻撃 |
| スライム `s` | 変則 | B3〜B7 | 1 | 0% | 分裂: 近接攻撃を受けて生き残ると 2 匹に (4 匹まで) | なし |
| オーク `o` | 戦士 | B4〜 | 2 | 0% | なし | なし |
| 幽霊 `G` | 変則 | B5〜 | 0 | 5% | 壁抜け | なし |
| トロル `T` | 重装 | B6〜 | 3 | 0% | 再生 (毎ターン HP 1)、鈍重 (2 ターンに 1 回) | 強打 25%: 防具を無視 |
| 狼 `w` | 俊敏 | B7〜 | 1 | 10% | 俊敏 | 跳びかかり 40%: 距離 2 から一気に隣接して攻撃 |
| ドラゴン `D` | ボス | B9〜 (1 体) | 3 | 0% | なし | 火炎 30%: 距離 2〜4 で炎 (攻撃力の半分 + 階数、防具で軽減) |

HP は階が深いほど、攻撃力は 3 階ごと、防御力は 4 階ごとに上がる (`createMonster`)。
敵の回避は 10% までに抑えてある。命中率と掛け算になるので、高いと外れ続ける run が出る。

## 開発

Node.js はビルドに使うだけで、遊ぶ側には不要である。

```sh
npm install
npm run dev       # http://localhost:5173/
npm run build     # dist/ に出力
npm run preview   # dist/ を配信して確認
npm test          # テスト
npm run balance   # バランス計測 (既定 100 run)
npm run icons     # public/icon-*.png を作り直す
```

### バランス計測

`npm run balance` は自動プレイを seed 違いで何度も回し、到達階の分布・階ごとの被弾・
レベルあたりの撃破数を表にして出す。

```sh
npm run balance          # 100 run
npm run balance -- 300   # run 数を指定する
```

seed は `SIM000` から順に振るので、同じ run 数なら何度回しても同じ結果になる。
数値を変える前と後で同じコマンドを打ち、表を見比べるのが使い方である。

自動プレイの方針は「隣の敵を殴る、危なくなったら飲む、近くのアイテムを拾う、階段へ向かう」の
4 つだけで、最適プレイの再現は狙っていない。変更の前後を同じ条件で比べるための物差しである。

## 構成

```
src/
  main.ts            起動。Renderer の選択、入力とループの接続
  game.ts            状態遷移 (1 ターン進める、戦闘、階層移動、死亡)。ViewModel を返す
  view.ts            描画層に渡すデータの型。見た目を含まない
  map.ts             部屋 + 通路の生成
  fov.ts             視界 (シャドウキャスティング)
  combat.ts          ダメージの計算式
  equip.ts           装備の定義と実効値
  entity.ts          プレイヤー・敵の定義と配置
  rng.ts             シード付き乱数
  input.ts           キーボードと画面ボタンを同じ Action に揃える
  save.ts            localStorage の保存と復元
  sim/               バランス計測 (本編のビルドには入らない)
    autoplay.ts      ヘッドレスの自動プレイ
    report.ts        結果を表に畳む
  render/
    renderer.ts      Renderer インターフェース
    text-renderer.ts Canvas に文字グリッドを描く
    glyphs.ts        種類 → 文字・色の対応表
public/
  sw.js              オフライン用 Service Worker
  manifest.webmanifest
  icon-*.png
scripts/
  balance.ts         バランス計測の入口
  make-icons.mjs     アイコン生成
```

テストは `src/**/*.test.ts` に置く。

見た目をタイル画像に替えたいときは、`Renderer` を実装した `TileRenderer` を `src/render/` に足し、
`src/main.ts` で差し込む。`game.ts` と `view.ts` は `render/` を import しない。

## 公開

`main` に push すると `.github/workflows/pages.yml` がビルドして GitHub Pages に配信する。
リポジトリの Settings → Pages で Source を「GitHub Actions」にしておく。

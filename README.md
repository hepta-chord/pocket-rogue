# Pocket Rogue

文字だけのカジュアルローグライク。
スマートフォンのブラウザで遊ぶ前提で、GitHub Pages に置いて URL で配る。
ホーム画面に追加すればアプリのように起動し、オフラインでも動く。

## 遊び方

- 画面下のボタンで 8 方向に移動。中央は待機
- ボタンを長押しすると連続移動。壁・敵の出現・被弾・階段で止まる
- 敵に向かって移動すると攻撃
- **斜めに動くとき、隣が片方でも壁なら通れない。** 壁の角は斜めに回り込めない。
  この制限は敵にもかかる (壁抜けの敵だけが例外)
- ログは自分の行動が青、敵の行動が赤、情報が灰、警告が黄。
  最新のターンの行だけが明るく、それ以前は暗い。どこまでが今の 1 手の結果かが読める
- 敵のグリフは傷つくほど赤に寄る。半分以下で橙、1/4 以下で赤になる
- 被弾すると画面が一瞬赤く光る
- 敵を倒すと経験値が入る。**レベルが上がると最大 HP が 3 増え、HP が全快する。**
  瀕死のまま踏み込んで全回復を取りにいくかどうかが判断になる
- 必要経験値は `6 + レベル×(レベル+1)/2` で、レベルが上がるほど伸び幅も増える
- **攻撃力はレベルでは伸びない。武器で決まる。** 素の攻撃力 4 に武器の補正が乗る
- ダメージは 1 から最大値までの一様乱数ではなく、下限が最大値に比例する
  (自分は 6 割から、敵は 5 割から)
- 防御は被ダメージを減らすが、出目の 1/4 は必ず通る。防具を積んでも軽減率は 75% で止まる
- 敵にも防御力がある。硬さは系統で違う (重装が硬く、群れと俊敏は柔らかい)
- **スタミナがある間だけ HP が自然回復する。** 6 ターンに 1 回復する
- スタミナは 5 ターンに 1、被弾のたびに 1 減る。**尽きると自然回復が止まり、毎ターン HP が 1 減る**
- 回復手段はレベルアップの全回復、自然回復、HP 回復薬、スタミナ薬の 4 つである。
  階層を降りただけでは強くならないので、倒す敵を選ぶことが判断になる
- アイテムは踏むと拾う。武器 `)` と防具 `[` は踏むと持ち替えるかどうかを聞かれる。
  **確認画面に数値・命中率・効く系統・特殊効果がすべて出る。** 名前から推測する必要は無い
- 持ち替えると今の装備は足元に落ちる。断った装備は、通っても二度は聞かれない
- 今の装備の性能は、右上の ≡ から確認できる
- 攻撃には命中率がある。武器ごとに違い、外すとダメージは 0 になる
- 防具には回避率がある。成立すると被弾しない
- 敵を倒すと、その系統に効く装備をたまに落とす
- 方向ボタンの上のスロットをタップして使う (対象指定は無い)
  - HP 回復薬 `!` (桃): HP を最大値の 1/4 回復する。5 個まで持てる
  - スタミナ薬 `!` (水色): スタミナを 30 戻す。3 個まで持てる
  - 雷 `*`: 見えている敵全員にダメージ。スタミナを 15 使う
- `~` はイベント床。踏むと効果が出て消える。色で効果の大きさと危なさが分かる
  - 青: HP を全回復する。立て直しの拠点で、各階に 1 つ必ずある
  - 緑: 小さなプラス (回復・スタミナ・経験値)。15% で小ダメージ
  - 黄: 中くらいのプラス (攻撃力・防御力・スタミナ最大値・高速移動)。30% でマイナス
  - 赤: 大きなプラス (地形が見える、能力の増加)。50% でマイナス。**腐食は赤だけ**
- 黄と赤は迂回できる位置にしか出ない。階段への唯一の通路には置かれない
- 腐食すると装備の強さが 1 下がる。変則よけの護符を着ていると防げる
- `>` に乗ると確認が出る。降りるかどうかを選ぶ (長押しの連続移動で踏んでも降りない)。
  確認が出るのは踏み入れたときと階段の上で待ったときだけで、その場で戦っている間は出ない
- 右上の ≡ から seed を確認・入力できる。同じ seed なら同じダンジョンになる
- PC はカーソルキー・テンキー・hjklyubn で移動、`.` か Space で待機

### 階のバリエーション

B3 以降、階の作りが変わることがある。降りた直後にログで知らせる。

| 種類 | 出る階 | 割合 | 内容 |
|---|---|---|---|
| 部屋 + 通路 | 全階 | 既定 | 一番近い部屋どうしを通路で結ぶ。枝分かれと行き止まりができる |
| 大部屋 | B3〜 | 8% | 盤面のほとんどが 1 つの部屋。見通しはよいが逃げ場がない |
| 迷路 | B3〜 | 6% | 部屋を作らず通路だけ。曲がり角が続く |
| 暗闇 | B4〜 | 15% | 視界が 7 マスから 3 マスに縮む。作りとは別に重なる |
| モンスターハウス | B4〜 | 18% | 行き止まりの部屋に敵と装備が密集する。入ると起動する |

モンスターハウスは行き止まりの部屋にしか出ない。
階段までの経路上に出ると迂回できず、「入らなければ安全、入れば報酬」という選択にならない。
ハウスのある階では、時間による追加の湧きは止まる。

### 長居への対策

同じ階に留まり続けると、3 つの圧が順に効いてくる。

- スタミナが減る (全体のターン数)
- 45 ターンごとに敵が 1 体湧く。視界の外にだけ出る。経験値とドロップは半分
- 200 ターンで予告が出て、240 ターンで `X` 追う者が現れる

追う者は勝てない強さだが、速くはないので逃げ切れる。
経験値は 0 で、倒せてもスコアだけが入る。
予告には階段の方角が添えられるので、位置が分からないまま詰むことはない。

### 装備

定義は `src/equip.ts` にある。
軸を 2 つずつ持たせて、単純な上位互換が生まれないようにしてある。

| 種別 | 軸 1 | 軸 2 |
|---|---|---|
| 武器 | 攻撃力 | 命中率 |
| 防具 | 減算値 | 回避率 |

深さから決まる強さ (武器 `1 + 階/3 + 0〜1`、防具 `1 + 階/4`) に、種類ごとの補正が乗る。
系統特効はその系統の敵が落とす。ドロップ限定のものは床には出ない。

| 武器 | 系統 | 攻撃 | 命中 | 効果 |
|---|---|---|---|---|
| 短剣 | - | -1 | 95% | - |
| 剣 | - | +0 | 85% | - |
| 斧 | - | +2 | 70% | - |
| 群れ薙ぎ | 群れ | -1 | 85% | 隣接する敵すべてに当たる |
| 韋駄天突き | 俊敏 | +0 | 100% | 必ず当たる。回避を無視する |
| 鎧通し | 戦士 | -1 | 85% | 防御力を無視する |
| 祓いの杖 | 変則 | -1 | 90% | 分裂を止める |
| 大槌 | 重装 | +3 | 65% | (攻撃力の高さが再生を上回る) |
| 会心の刃 | ドロップ限定 | +0 | 85% | 25% で防御力を無視する |
| 双牙 | ドロップ限定 | -2 | 80% | 2 回攻撃する |

| 防具 | 系統 | 防御 | 回避 | 効果 |
|---|---|---|---|---|
| 革鎧 | - | -1 | 12% | - |
| 鎖帷子 | - | +0 | 5% | - |
| 板金鎧 | - | +2 | 0% | - |
| 群れよけの盾 | 群れ | +0 | 5% | 被弾時のスタミナ消費を抑える (スタミナ実装後) |
| 疾風の外套 | 俊敏 | -1 | 20% | (回避の高さが速い敵に効く) |
| 戦士殺しの鎧 | 戦士 | +2 | 0% | (減算値の高さが素直な強敵に効く) |
| 変則よけの護符 | 変則 | +0 | 5% | 腐食を防ぐ (腐食実装後) |
| 棘鎧 | 重装 | +1 | 0% | 近接攻撃に反撃する |
| 影衣 | ドロップ限定 | -2 | 28% | - |
| 金剛の鎧 | ドロップ限定 | +4 | 0% | - |

### 敵

特徴は「パッシブ (常に働く性質)」と「アクション (条件が揃ったとき確率で使う技)」に分かれる。
定義は `src/entity.ts` の `MONSTERS` にある。

敵は 5 系統 × 3 グレード + ボスの 16 種である。
グレードは種類ごとに階層を割り当てるのではなく、同じ系統の変種として変化する。
系統ごとに文字と基になる生き物を固定してあるので、文字で「何系か」、色と名前で「どのくらい強いか」が読める。

グレードは 10 階ごとに切り替わる (B1〜B10 が 1、B11〜B20 が 2、B21 以降が 3)。

| 系統 | 文字 | グレード 1 | グレード 2 | グレード 3 | 役割と伸びる方向 |
|---|---|---|---|---|---|
| 群れ | `r` | ネズミ (B1〜) | 毒ネズミ | 腐れネズミ | 1 体は弱く数で押す。毒・腐食の付与攻撃が付く |
| 俊敏 | `b` | コウモリ (B1〜) | 疾風コウモリ | 雷コウモリ | 速い、逃げられない。跳びかかりが付く |
| 戦士 | `g` | ゴブリン (B2〜) | 重装ゴブリン | ゴブリン王 | 素直に強い。連撃率と装備の質が上がる |
| 変則 | `s` | スライム (B3〜) | 幽体スライム | 擬態スライム | 通常の戦い方が通じない。分裂 → 壁抜け → 擬態と重なる |
| 重装 | `T` | トロル (B6〜) | 岩トロル | 鉄トロル | 高 HP、鈍足、再生。強打の発生率が上がる |
| ボス | `D` | ドラゴン (B9〜) | - | - | 火炎を吐く |
| - | `X` | 追う者 | - | - | 長居すると現れる。勝てない。経験値は 0 |

パッシブとアクションは次のとおり。

| 名前 | 内容 |
|---|---|
| 俊敏 | 1 ターンに 2 回行動する (攻撃は 1 回まで) |
| 鈍重 | 2 ターンに 1 回しか行動しない |
| 再生 | 毎ターン HP が 1 回復する |
| ふらつき | 追うとき半分の確率で狙いがそれる |
| 壁抜け | 壁の中を移動できる。角の斜め移動の制限も受けない |
| 分裂 | 近接攻撃を受けて生き残ると 2 匹に割れる (4 匹まで) |
| 擬態 | 落ちている武器 `)` に化けている。隣に来るか殴るまで動かない |
| 連撃 | 隣接時、2 回攻撃する |
| 強打 | 隣接時、防具を無視した一撃 |
| 跳びかかり | 距離 2 から一気に隣接して攻撃する |
| 火炎 | 距離 2〜4 で炎を吐く (攻撃力の半分 + 階数、防具で軽減) |
| 毒牙 | 隣接時、毒を与える。8 ターンのあいだ毎ターン HP が 1 減る |
| 腐食噛み | 隣接時、装備を腐食させる |

HP は階が深いほど、攻撃力は 3 階ごと、防御力は 4 階ごとに上がる (`createMonster`)。
グレードの境目で数値が飛ばないように、次のグレードの基礎値は
前のグレードが最深部で持つ値から続くように置いてある。

敵の回避は 15% までに抑えてある。命中率と掛け算になるので、高いと外れ続ける run が出る。

## 開発

Node.js はビルドに使うだけで、遊ぶ側には不要である。

```sh
npm install
npm run dev       # http://localhost:5173/
npm run build     # dist/ に出力
npm run preview   # dist/ を配信して確認
npm test          # テスト
npm run balance   # バランス計測 (既定 100 run)
npm run icons     # public/icon-*.png を作り直す
```

### バランス計測

`npm run balance` は自動プレイを seed 違いで何度も回し、到達階の分布・階ごとの被弾・
レベルあたりの撃破数を表にして出す。

```sh
npm run balance          # 100 run
npm run balance -- 300   # run 数を指定する
```

seed は `SIM000` から順に振るので、同じ run 数なら何度回しても同じ結果になる。
数値を変える前と後で同じコマンドを打ち、表を見比べるのが使い方である。

自動プレイの方針は「隣の敵を殴る、危なくなったら飲む、近くのアイテムを拾う、階段へ向かう」の
4 つだけで、最適プレイの再現は狙っていない。変更の前後を同じ条件で比べるための物差しである。

## 構成

```
src/
  main.ts            起動。Renderer の選択、入力とループの接続
  game.ts            状態遷移 (1 ターン進める、戦闘、階層移動、死亡)。ViewModel を返す
  view.ts            描画層に渡すデータの型。見た目を含まない
  map.ts             部屋 + 通路の生成、経路の判定
  fov.ts             視界 (シャドウキャスティング)
  combat.ts          ダメージの計算式
  equip.ts           装備の定義と実効値
  floors.ts          イベント床の定義と配置
  entity.ts          プレイヤー・敵の定義と配置
  rng.ts             シード付き乱数
  input.ts           キーボードと画面ボタンを同じ Action に揃える
  save.ts            localStorage の保存と復元
  sim/               バランス計測 (本編のビルドには入らない)
    autoplay.ts      ヘッドレスの自動プレイ
    report.ts        結果を表に畳む
  render/
    renderer.ts      Renderer インターフェース
    text-renderer.ts Canvas に文字グリッドを描く
    glyphs.ts        種類 → 文字・色の対応表
public/
  sw.js              オフライン用 Service Worker
  manifest.webmanifest
  icon-*.png
scripts/
  balance.ts         バランス計測の入口
  make-icons.mjs     アイコン生成
```

テストは `src/**/*.test.ts` に置く。

見た目をタイル画像に替えたいときは、`Renderer` を実装した `TileRenderer` を `src/render/` に足し、
`src/main.ts` で差し込む。`game.ts` と `view.ts` は `render/` を import しない。

## 公開

`main` に push すると `.github/workflows/pages.yml` がビルドして GitHub Pages に配信する。
リポジトリの Settings → Pages で Source を「GitHub Actions」にしておく。

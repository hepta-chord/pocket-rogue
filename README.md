# Pocket Rogue

文字だけのカジュアルローグライク。
スマートフォンのブラウザで遊ぶ前提で、GitHub Pages に置いて URL で配る。
ホーム画面に追加すればアプリのように起動し、オフラインでも動く。

## 遊び方

- 画面下のボタンで 8 方向に移動。中央は待機
- ボタンを長押しすると連続移動。壁・敵の出現・被弾・階段で止まる
- **「待つ」も長押しでターンを送れる。** スタミナが HP に変わるので、降りる前の立て直しに使う。
  敵が見えたとき、被弾したとき、HP が満タンになったときに止まる
- 敵に向かって移動すると攻撃
- **斜めに動くとき、隣が片方でも壁なら通れない。** 壁の角は斜めに回り込めない。
  この制限は敵にもかかる (壁抜けの敵だけが例外)
- **攻撃にも同じ制限がかかる。壁の角越しには殴れない。** 自分も敵も届かない。
  通路の入口に立てば、部屋側の敵は正面の 1 体しか攻撃できない。
  例外は壁抜けの敵と、遠距離攻撃を持つ敵だけである
- **遠隔の敵 `k` は、通路に下がっても直線上なら届く。** 槍は 2 マス先、弓は 6 マス先まで。
  下がって待つ戦い方に対する唯一の答えなので、見えたら詰めて潰すのが基本になる
- **遠隔の攻撃は射線上の最初のものに当たる。** 味方が前に詰まっていれば味方に当たる。
  当てて倒すと撃った側のグレードが上がるが、その経験値はこちらには入らない。
  敵を通路に詰めさせるほど同士討ちは起きやすく、そのぶん 1 体が強くなって返ってくる
- ログは 6 行表示。自分の行動が青、敵の行動が赤、情報が灰、警告が黄。
  20 ターン以上なにも起きなければ古い行は消える。
  移動や待機ではログが出ないので、放置した開幕メッセージがいつまでも残らないようにしてある。
  最新のターンの行だけが明るく、それ以前は暗い。どこまでが今の 1 手の結果かが読める
- 敵のグリフは傷つくほど赤に寄る。半分以下で橙、1/4 以下で赤になる
- 被弾すると画面が一瞬赤く光る
- 敵を倒すと経験値が入る。**レベルが上がると最大 HP が 3 増え、HP が全快する。**
  瀕死のまま踏み込んで全回復を取りにいくかどうかが判断になる
- 必要経験値は `6 + レベル×(レベル+1)/2` で、レベルが上がるほど伸び幅も増える
- **レベルが階数より進みすぎると、入る経験値が減る。** 基準は `階数 + 6` で、
  超えた 1 レベルにつき 1/2、1/3、1/4 と落ちていく。減ったぶんはスコアに回る。
  さらに、減った量に応じて追う者の時計が進む。
  頭打ちのまま狩り続けると点は伸びるが、追われるのが早くなる
- **攻撃力はレベルでは伸びない。武器で決まる。** 素の攻撃力 4 に武器の補正が乗る
- ダメージは 1 から最大値までの一様乱数ではなく、下限が最大値に比例する
  (自分は 6 割から、敵は 5 割から)
- 防御は被ダメージを減らすが、出目の 1/4 は必ず通る。防具を積んでも軽減率は 75% で止まる
- 敵にも防御力がある。硬さは系統で違う (重装が硬く、群れ・俊敏・遠隔は柔らかい)
- **スタミナがある間だけ HP が自然回復する。** 6 ターンに 1 回復する
- スタミナは初期値 250 で、12 ターンに 1、被弾 3 回ごとに 1 減る。
  **尽きると自然回復が止まり、毎ターン HP が 1 減る**
- 回復手段はレベルアップの全回復、自然回復、HP 回復薬、スタミナ薬、5 階ごとの休憩床の 5 つである。
  階層を降りただけでは強くならないので、倒す敵を選ぶことが判断になる
- アイテムは踏むと拾う。武器 `)` と防具 `[` は踏むと持ち替えるかどうかを聞かれる。
  **確認画面に数値・命中率・特殊効果がすべて出る。** 名前から推測する必要は無い
- 持ち替えると今の装備は足元に落ちる。断った装備は、通っても二度は聞かれない
- 今の装備の性能は、右上の ≡ から確認できる
- 攻撃には命中率がある。武器ごとに違い、外すとダメージは 0 になる
- 防具には回避率がある。成立すると被弾しない
- **床に落ちている装備と、敵が落とす装備は品揃えが違う。**
  床には基礎と扱いやすい効果、ドロップには尖った効果が出る
- 手強い系統ほど装備を落としやすい (重装 > 変則 > 遠隔 > 戦士 > 俊敏 > 群れ)
- 方向ボタンの上のスロットをタップして使う (対象指定は無い)
  - HP 回復薬 `!` (桃): HP を最大値の 1/2 回復する。5 個まで持てる
  - スタミナ薬 `!` (水色): スタミナを 40 戻す。3 個まで持てる
  - 地図 `?` (黄): 階の地形と、隠れている罠がすべて分かる。**スタミナを 20 使う。** 2 個まで持てる
  - 雷 `*`: 見えている敵全員にダメージ。スタミナを 15 使う。
    **単体では威力は変わらず、巻き込む数が多いほど 1 体あたりの威力が上がる。**
    通路に下がって 1 対 1 を作る戦術と競合しないよう、単体を狙う理由にはならない形にしてある。
    **ボス (ドラゴン・追う者) には効かない。** 範囲攻撃で押し切られるとボスがボスとして
    機能しないので、そこだけ通用しない札にしてある。耐性持ちは巻き込み数にも数えない
- **`^` は罠。踏むまで見えない。** 踏むと発動して消える。どれも即死はしない
  - 腐食の罠: 装備が弱る。取り返しがつかないので、出やすさは低くしてある
  - 呼び寄せの罠: 視界の外に敵が 2〜3 体湧く
  - 足止めの罠: 4 ターン動けない。隣に敵がいると危ない
  - 衰弱の罠: HP が半分になる。1 は残る
  - 疲労の罠: スタミナが半分になる
  - 落とし穴: 下の階へ落ちる。階段を探さずに済むので、得になることもある
- 罠は地図を使うと位置が分かる。見えないものへの唯一の対抗手段である
- **見つかった落とし穴だけは `v` で別に描く。** 他の罠は損をするだけだが、
  落とし穴は次の階へ降ろしてくれるので「あえて踏む」が選択肢になる。
  区別が付かないとその選択ができない
- **`~` は休憩床。5 階ごとに 1 つだけ置かれる。** HP を全回復し、スタミナも 50 戻す立て直しの拠点である。
  かつては色ごとに別のイベント床 (緑・黄・赤) もあったが、そのマイナス側は罠と同じ骨格だったので
  罠へ一本化した。見えるイベントとして残るのはこの休憩床だけである
- `$` は財宝。踏むとスコアになる
- `>` に乗ると確認が出る。降りるかどうかを選ぶ (長押しの連続移動で踏んでも降りない)。
  確認が出るのは踏み入れたときと階段の上で待ったときだけで、その場で戦っている間は出ない。
  **一度断ったら、階段から離れるまで聞き直さない。** 断るたびに聞かれると、
  階段の上で待って休むことができなくなる (装備を断ったときの印と同じ考え方である)
- **落とし物は 1 マスに 1 つだけ。** 階段・罠・休憩床・他のアイテムと同じマスには落ちず、
  そこから一番近い「何も無い床」まで転がる。歩いて行ける道をたどって探すので、
  壁の中で倒した壁抜けの敵の落とし物も拾いに行ける
- 右上の ≡ から seed を確認・入力できる。同じ seed なら同じダンジョンになる
- **≡ の「遊び方」に、画面に出る文字の一覧がある。** 地形・アイテム・敵・戦い方の 4 つに分けてある。
  文字と色を知っているのは描画層だけなので、対応表も `src/render/help.ts` に置き、
  名前は `entity.ts` / `items.ts` / `traps.ts` の定義から引いている
  (敵や罠を足したときに説明だけ古くなることはない)
- 死ぬと結果の画面が出る。次の run へは「新しい seed で始める」「同じ seed でもう一度」
  「seed を選んで始める」の 3 つから選ぶ。
  **この画面は何度でも開き直せる。** 閉じたあとに方向ボタンを押しても、
  アプリを開き直しても戻ってくるので、終わった盤面だけが残って手詰まりになることはない
- PC はカーソルキー・テンキー・hjklyubn で移動、`.` か Space で待機

### ボスとクリア

| 階 | 内容 |
|---|---|
| 10F, 20F | ドラゴン `D` が出る。倒すと財宝 `$` を落とす。倒さず降りてもよい |
| 30F | ドラゴンを倒すと脱出階段 `<` が現れる。上るとクリア (加点 1000) |
| 31F 以降 | 同じ構成を繰り返す。60F、90F も脱出できる |

下り階段はボス階でも最初から出ている。
避けて降りる選択肢を残し、報酬をスコアにすることで戦う判断に見返りを与えている。
脱出を断ればそのまま潜り続けられるので、クリアと周回のどちらも成立する。

階が深いほど敵の HP と攻撃力は伸び続けるので、周回しても難易度は頭打ちにならない。

### 階のバリエーション

B3 以降、階の作りが変わることがある。降りた直後にログで知らせる。

| 種類 | 出る階 | 割合 | 内容 |
|---|---|---|---|
| 部屋 + 通路 | 全階 | 既定 | 一番近い部屋どうしを通路で結ぶ。枝分かれと行き止まりができる |
| 大部屋 | B3〜 | 8% | 盤面のほとんどが 1 つの部屋。見通しはよいが逃げ場がない |
| 迷路 | B3〜 | 6% | 部屋を作らず通路だけ。曲がり角が続く。行き止まりの 8 割は塞いで輪にしてある |
| 暗闇 | B4〜 | 15% | 視界が 7 マスから 3 マスに縮む。作りとは別に重なる |
| モンスターハウス | B4〜 | 18% | 行き止まりの部屋に敵と装備が密集する。入ると起動する |

モンスターハウスは行き止まりの部屋にしか出ない。
階段までの経路上に出ると迂回できず、「入らなければ安全、入れば報酬」という選択にならない。
ハウスのある階では、時間による追加の湧きは止まる。

### 長居への対策

同じ階に留まり続けると、3 つの圧が順に効いてくる。

- スタミナが減る (全体のターン数)
- 25 ターンごとに敵が 1 体湧く。視界の外にだけ出る。経験値とドロップは半分
- 120 ターンで予告が出て、150 ターンで `X` 追う者が現れる。
  レベルが頭打ちの状態で狩ると、この時計が余分に進む

閾値は 1 階の滞在ターン (中央値 66) のおよそ 1.8 倍と 2.3 倍にあたる。
200 / 250 まで上げていた頃は、出現に達するフロアが全体の 2% しかなく、圧としてほぼ働いていなかった。
今は 4.9% の階で出現する。

追う者は勝てない強さだが、速くはないので逃げ切れる。雷も効かない。
経験値は 0 で、倒せてもスコアだけが入る。
予告には階段の方角が添えられるので、位置が分からないまま詰むことはない。

### 装備

定義は `src/equip.ts` にある。
軸を 2 つずつ持たせて、単純な上位互換が生まれないようにしてある。

| 種別 | 軸 1 | 軸 2 |
|---|---|---|
| 武器 | 攻撃力 | 命中率 |
| 防具 | 減算値 | 回避率 |

深さから決まる強さ (武器 `1 + 階/3 + 0〜1`、防具 `1 + 階/4`) に、種類ごとの補正が乗る。

**床とドロップで品揃えを分けてある。**
拾うことと狩ることが別の意味を持つようにするためで、床の装備はドロップからは出ないし、その逆も出ない。

#### 床に出る装備

| 短剣 | -1 | 95% | - |
| 剣 | +0 | 85% | - |
| 斧 | +2 | 70% | - |
| 薙ぎ払い | -1 | 85% | 隣接する敵すべてに当たる |
| 韋駄天突き | +0 | 100% | 必ず当たる。回避を無視する |

| 防具 | 防御 | 回避 | 効果 |
|---|---|---|---|
| 革鎧 | -1 | 12% | - |
| 鎖帷子 | +0 | 5% | - |
| 板金鎧 | +2 | 0% | - |
| 疾風の外套 | -1 | 20% | - |
| 棘鎧 | +1 | 0% | 近接攻撃に反撃する |

### 敵

特徴は「パッシブ (常に働く性質)」と「アクション (条件が揃ったとき確率で使う技)」に分かれる。
定義は `src/entity.ts` の `MONSTERS` にある。

敵は 6 系統 × 3 グレード + ボス 2 種である。
系統ごとに文字と基になる生き物を固定してあるので、文字で「何系か」、色と名前で「どのくらい強いか」が読める。

**系統ごとに出る帯をずらし、あいだに空白期間を置いてある。**
1 つの階に出るのは 2〜5 系統だけで、6 系統が揃うのは B25 からである。
全系統が全階に出ると、10 階のあいだ顔ぶれが変わらず、階の特色が出ない。

| 系統 | 文字 | グレード 1 | グレード 2 | グレード 3 |
|---|---|---|---|---|
| 群れ | `r` | B1〜B5 | B9〜B14 | B18〜 |
| 俊敏 | `b` | B2〜B8 | B11〜B16 | B20〜 |
| 遠隔 | `k` | B3〜B9 | B11〜B17 | B22〜 |
| 戦士 | `g` | B6〜B10 | B14〜B19 | B23〜 |
| 重装 | `T` | B8〜B13 | B16〜B21 | B25〜 |

30F でクリアになるので、15 種すべてが B25 までに出そろうように詰めてある。

**変則 `s` は上の巡回に入れず、全階に出る特殊枠として扱う。**
分裂・壁抜け・擬態は「通常の戦い方が通じない」ための性質なので、
どの深さにも 1 つはある方が戦い方の幅として機能する。
そのぶん数値の伸びは緩めてある (HP は階の 0.6、攻撃力は階の 0.28)。

| 系統 | 文字 | グレード 1 | グレード 2 | グレード 3 |
|---|---|---|---|---|
| 変則 | `s` | B1〜B10 | B11〜B20 | B21〜 |

顔ぶれが変わるのは B2、B3、B6、B8、B10、B11、B14、B16、B18、B20、B22、B23、B25 と 1〜3 階ごとに来る。

**遠隔だけは空白期間を B10 の 1 階に詰めてある。**
「通路に下がって待つ」への対抗手段なので、抜けている階では通路戦術が万能に戻り、
その階だけ遊び方の幅が狭くなる。抜くのはボス階だけにして、そこはドラゴンに場を譲る。
B1〜B10 のあいだに一度も遭遇しない確率は 0.03% である。
B6 で群れが消えて戦士が出る、B9 で毒ネズミが戻ってくる、といった形になる。

| 系統 | グレード 1 | グレード 2 | グレード 3 | 役割と伸びる方向 |
|---|---|---|---|---|
| 群れ | ネズミ | 毒ネズミ | 腐れネズミ | 1 体は弱く数で押す。B1 から死にうる。毒・腐食の付与攻撃が付く |
| 俊敏 | コウモリ | 疾風コウモリ | 雷コウモリ | 速い、逃げられない。跳びかかりが付く |
| 戦士 | ゴブリン | 重装ゴブリン | ゴブリン王 | 素直に強い。連撃率と装備の質が上がる |
| 変則 | スライム | 幽体スライム | 擬態スライム | 通常の戦い方が通じない。分裂 → 壁抜け → 擬態と重なる |
| 重装 | トロル | 岩トロル | 鉄トロル | 高 HP、鈍足。強打の発生率が上がる。再生はグレード 3 だけ |
| 遠隔 | 槍コボルト | 弓コボルト | 狙撃コボルト | 間合いの外から削る。柔らかい。射線上の味方を巻き込み、倒すと成り上がる |
| ボス | ドラゴン `D` | - | - | 火炎を吐く。雷が効かない。倒すと財宝を落とす |
| - | 追う者 `X` | - | - | 長居すると現れる。勝てない。雷も効かない。経験値は 0 |

**階に出す種類の抽選は、群れの頭数ぶんを割り引いてある。**
群れは 1 回の抽選で 3〜6 体まとめて出る (`pack`) ので、他の系統と同じ確率で抽選すると、
選ばれるたびに頭数だけ大きく増え、階の構成が群れに偏る。
抽選の重みを「1 回あたりの平均頭数」で割ることで、頭数ベースで見た出現比率を他の系統に近づけてある
(`weightedPick`)。

| 名前 | 内容 |
|---|---|
| 俊敏 | 1 ターンに 2 回行動する (攻撃は 1 回まで) |
| 鈍重 | 2 ターンに 1 回しか行動しない |
| 再生 | 毎ターン HP が 1 回復する |
| ふらつき | 追うとき半分の確率で狙いがそれる |
| 壁抜け | 壁の中を移動できる。角の斜め移動の制限も受けない |
| 分裂 | 近接攻撃を受けて生き残ると 2 匹に割れる (同種 4 匹まで)。分裂体は装備を落とさず、経験値とスコアが 1/5 になる |
| 擬態 | 落ちている武器 `)` に化けている。隣に来るか殴るまで動かない |
| 連撃 | 隣接時、2 回攻撃する |
| 強打 | 隣接時、防具を無視した一撃 |
| 跳びかかり | 距離 2 から一気に隣接して攻撃する |
| 火炎 | 距離 2〜4 で炎を吐く (攻撃力の半分 + 階数、防具で軽減) |
| 角越し | 壁の角越しにも攻撃が届く (現時点で持つ敵はいない) |
| 槍 | 直線上なら 2 マス先にも突きが届く。間にいるものを巻き込む |
| 成り上がり | 味方を倒すと次のグレードに変わり、HP も上がった先の値まで戻る |
| 射撃 | 見えていて直線上に並んでいるとき、2〜6 マス先から射る。間にいるものを巻き込む |
| 雷耐性 | 雷が効かない。巻き込み数にも数えない。ボス 2 種が持つ |
| 毒牙 | 隣接時、毒を与える。8 ターンのあいだ毎ターン HP が 1 減る (重ね掛けは 12 ターンまで) |
| 腐食噛み | 隣接時、装備を腐食させる |

HP と攻撃力の伸び方は系統ごとに違う (`GROWTH`)。
巡回する 5 系統は HP が階の 3/4、攻撃力が 3 階ごとに上がる。
補正は出現階からの差ではなく**絶対の階数**で掛ける。
差で掛けると、帯に入った直後の敵が基礎値のまま出て、同じ階の他の敵より弱くなる。

**防御力は深さで伸ばさない。** 系統ごとの硬さを表す固定値である。
伸ばすとプレイヤーの攻撃力の伸び (階/3) をほぼ打ち消してしまい、
与ダメージが深さに対して横ばいになる。敵の HP は伸びるので、深いほど 1 体に要する手数だけが増えて壁になる。
**経験値とスコアも階が深いほど増える** (`xpFor`)。
同じ敵でも深いほど価値が上がるので、どの階でも 3〜10 体で 1 レベル上がる。
掛けるのは絶対の階数なので、グレードが切り替わる階で 1 体の価値が下がることはない。

基礎値は「その系統・グレードの持ち味」を表す。階の水準は深さ補正が受け持つので、
出現階をずらしても数値が飛ばない。

敵の回避は 15% までに抑えてある。命中率と掛け算になるので、高いと外れ続ける run が出る。

### 難易度の目安

400 run の自動プレイでの結果である。

| 指標 | 値 |
|---|---|
| 到達階 | 中央値 B15 |
| B5 到達率 | 88% |
| B10 到達率 | 78% |
| B20 到達率 | 12% |
| ボス撃破率 | 89% |
| 主な死因 | 追う者 21%、重装ゴブリン 15%、スタミナ切れ 15%、遠隔 10%、岩トロル 6% |

重装の再生をグレード 3 だけに絞り、回復薬を最大 HP の 1/2 に上げたことで、
B20 到達率が 3% から 12%、ボス撃破率が 77% から 89% に上がった。
回復薬の出る数を 6 から 4 に絞る案も測ったが、B20 到達率が 8% に落ちたので採らなかった。
量と数の両方を絞ると、深層が元から目標に届いていない側にさらに寄る。

**追う者が死因の 1 位である (21%)。** 閾値を変えたわけではなく、
run が深くまで届くようになって 1 run あたりの階数が増えたためである。
階あたりで見ると 1.55%、追う者が出る階は全体の 4.9% で、そこは前回から動いていない。

B14 から B15 にかけて出目が跳ねて 1 ダメージ率が 29%→5% に落ちる段差は残っている
(グレード 2 の系統が出そろう時期と重なる)。

**序盤の脱落率は狙いよりまだ低い** (B10 到達 78% に対して、狙いは 40〜50%)。
B1 で終わる率も 1.3% で、狙いの 5% には届いていない。
30F クリアは今のところ自動プレイの範囲外である。

自動プレイは敵が 2 体以上見えると通路へ下がって 1 対 1 を作る。
遠隔の敵が見えたときだけは下がらずに詰めるようにしてあり、
「通路戦術は遠隔に弱い」という設計がそのまま測定にも乗るようにしてある。

### バランス計測

`npm run balance` は自動プレイを seed 違いで何度も回し、到達階の分布・階ごとの被弾・
レベルあたりの撃破数を表にして出す。

```sh
npm run balance          # 100 run
npm run balance -- 300   # run 数を指定する
```

seed は `SIM000` から順に振るので、同じ run 数なら何度回しても同じ結果になる。
数値を変える前と後で同じコマンドを打ち、表を見比べるのが使い方である。

自動プレイの方針は「隣の敵を殴る、危なくなったら飲む、近くのアイテムを拾う、階段へ向かう」の
4 つだけで、最適プレイの再現は狙っていない。変更の前後を同じ条件で比べるための物差しである。

src/
  main.ts            起動。Renderer の選択、入力とループの接続

  view.ts            描画層に渡すデータの型。見た目を含まない
  map.ts             部屋 + 通路の生成、経路の判定
  fov.ts             視界 (シャドウキャスティング)
  ai.ts              敵の移動 (距離場、包囲、迂回)
  traps.ts           罠の定義と配置
  combat.ts          ダメージの計算式
  equip.ts           装備の定義と実効値
  floors.ts          休憩床の定義と配置
  entity.ts          プレイヤー・敵の定義と配置
  rng.ts             シード付き乱数
  input.ts           キーボードと画面ボタンを同じ Action に揃える
  save.ts            localStorage の保存と復元
  sim/               バランス計測 (本編のビルドには入らない)
    autoplay.ts      ヘッドレスの自動プレイ
    report.ts        結果を表に畳む
  render/
    renderer.ts      Renderer インターフェース
    text-renderer.ts Canvas に文字グリッドを描く

scripts/
